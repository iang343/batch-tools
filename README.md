# batch-tools
A basic batch program with batch programming tools. Only for windows, only Windows 11 compatibility verified.

## What can this be used for?
Batch tools is a simple command line tool for making simple scripts, or terminal commands. Batch tools can be used to manage batch files, make templates, add simple commands to files, show lists of commands, show examples and use cases of commands, and finally automatically do simple tricks in the terminal eg; scrolling text.
## Installation

### Method 1; Wizard

For simple installation download the installation wizard, and run it.

### method 2; Moving files to correct directories

For custom installs or non-wizard installation you have multiple options. First decide what directory to put the script in, the users home folder is recommended. Second download the latest version of btools.bat from the latest folder. Move the btools.bat file to the correct directory, this directory will be the default for creating scripts. To make files be created in a different directory, cd to that directory in cmd, then paste in btools.bat's file path and click enter.


## How to Use
To use btools (installed via method 1) open a cmd, and run the command "btools". Then select the option you would like to preform in the menu.
